# Timer Performansi Panitia

> Alat bantu panitia untuk mengatur waktu penampilan dengan sinyal visual Hijau, Kuning, dan Merah.

🌐 **Live Demo:** [https://salmaimut.github.io/timer-performansi-panitia/](https://salmaimut.github.io/timer-performansi-panitia/)

## Fitur Utama
- Stopwatch hitung naik dari 0:00.
- Sinyal Hijau saat penampilan berlangsung.
- Sinyal Kuning otomatis saat 30 detik sebelum batas waktu.
- Sinyal Merah saat batas waktu tercapai.
- Audio beep peringatan saat transisi sinyal.
- Toggle tema Gelap/Terang.
- Responsif untuk mobile dan desktop.
- Local Storage untuk menyimpan pengaturan durasi dan peringatan.
- Single-file Vanilla HTML5, CSS3, & Modern ES6 JavaScript (No Build Tools Required).

## Cara Menjalankan Secara Lokal
Cukup buka file `index.html` di browser favorit Anda atau gunakan server lokal:
```bash
# Python simple server
python3 -m http.server 8000
```
